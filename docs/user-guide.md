## ESPAÑOL

### Task Board — Gestión de Tareas

**¿Qué ves al entrar?**

Un tablero Kanban con 5 columnas:

| Columna | Significado |
|---|---|
| **Open** | Tarea creada, aún no iniciada |
| **In Progress** | En proceso |
| **Proof Submitted** | Se subió evidencia, pendiente de revisión |
| **Approved** | Completada y aprobada |
| **Revision** | Requiere correcciones |

**Crear una tarea**

- Botón **+ New Task** (arriba derecha) o presiona la tecla **C**
- Llena: título, BU, tipo, prioridad, fecha límite, responsable
- Puedes usar una plantilla si ya existen configuradas
- Marca **"Proof required"** si necesitas evidencia fotográfica o en archivo

**Filtros**

- Por BU, prioridad, tipo o usuario
- Por defecto ves las tareas relacionadas contigo (asignadas, creadas por ti, o donde eres seguidor)
- Selecciona **"All users"** para ver todas

**Detalle de una tarea**

- Click en cualquier tarjeta para abrirla
- Desde ahí puedes:
  - Cambiar el estado
  - Reasignar a otro usuario
  - Subir evidencia (proof): foto, video, PDF o HTML
  - Dejar comentarios
  - Agregar seguidores
  - Archivar la tarea

> ⚠️ El estado **NO cambia automáticamente** al subir evidencia — debes moverlo manualmente a **Proof Submitted**.

**Notificaciones**

Recibes una notificación en la app (campana 🔔) y por correo cuando:

- Te asignan una tarea
- Cambia el estado de una tarea relacionada
- Hay un nuevo comentario
- Se sube evidencia

### CRM — Pipeline Comercial

**¿Qué es?**

Un pipeline visual para gestionar oportunidades comerciales: patrocinios, alianzas, publicidad, eventos.

**Etapas del pipeline**

| Etapa | Significado |
|---|---|
| **Lead** | Contacto identificado |
| **Contacted** | Ya hubo comunicación inicial |
| **Proposal** | Se envió propuesta |
| **Negotiation** | En negociación activa |
| **Won** | Cerrado — ganado |
| **Lost** | Cerrado — perdido |

**Crear un deal**

- Botón **+ New Deal** o tecla **D**
- Llena: nombre, valor estimado, probabilidad, BU, fecha de cierre esperada, contacto
- Puedes crear un contacto nuevo o elegir uno existente

**Gestionar un deal**

- Click en la tarjeta para abrir el panel de detalle
- Desde ahí:
  - Cambiar etapa
  - Editar información
  - Registrar actividad: llamada, correo, reunión, nota
  - Vincular tareas relacionadas
- Si se marca como perdido: se solicita razón de pérdida

**Mi pipeline / Todos**

- Por defecto ves solo tus deals
- Botón **"All Deals"** para ver el pipeline completo *(solo MASTER y C-Level)*

### Consejos generales

- **Perfil:** completa tu nombre y foto en la sección **Profile** para que tus compañeros te identifiquen
- **Campana de notificaciones:** el número rojo indica mensajes sin leer; click para marcarlos como leídos
- **Actualización en tiempo real:** la plataforma se actualiza automáticamente al cambiar de pestaña o cada 20 segundos

## ENGLISH

### Access / Login

- Open the app from your browser or home screen icon
- Sign in with your email and password, or with Google
- If you don't have an account, ask your administrator to send you an invitation

> **Recommended on iPhone:** Add the app to your home screen (Safari → share → "Add to Home Screen") to receive push notifications.

---

### Task Board

**What you see**

A Kanban board with 5 columns:

| Column | Meaning |
|---|---|
| **Open** | Task created, not started yet |
| **In Progress** | Currently being worked on |
| **Proof Submitted** | Evidence uploaded, pending review |
| **Approved** | Completed and approved |
| **Revision** | Needs corrections |

**Creating a task**

- Click **+ New Task** (top right) or press **C**
- Fill in: title, BU, type, priority, due date, assignee
- You can apply a template if your admin has configured them
- Check **"Proof required"** if photo or file evidence is needed

**Filters**

- Filter by BU, priority, type, or user
- By default you see tasks related to you (assigned to you, created by you, or where you're a follower)
- Select **"All users"** to see everything

**Task detail**

- Click any card to open it
- From there you can:
  - Change status
  - Reassign to another user
  - Upload proof: photo, video, PDF, or HTML
  - Leave comments
  - Add followers
  - Archive the task

> ⚠️ Status does **NOT change automatically** when proof is uploaded — move it manually to **Proof Submitted**.

**Notifications**

You receive an in-app notification (bell 🔔) and an email when:

- A task is assigned to you
- Status changes on a task you're related to
- A new comment is posted
- Evidence is uploaded

### CRM — Commercial Pipeline

**What is it?**

A visual pipeline to manage commercial opportunities: sponsorships, partnerships, advertising, events.

**Pipeline stages**

| Stage | Meaning |
|---|---|
| **Lead** | Identified contact |
| **Contacted** | Initial communication made |
| **Proposal** | Proposal sent |
| **Negotiation** | Actively negotiating |
| **Won** | Closed — won |
| **Lost** | Closed — lost |

**Creating a deal**

- Click **+ New Deal** or press **D**
- Fill in: name, estimated value, probability, BU, expected close date, contact
- Create a new contact or select an existing one

**Managing a deal**

- Click any card to open the detail panel
- From there:
  - Change stage
  - Edit deal info
  - Log activity: call, email, meeting, note
  - Link related tasks
- If a deal is marked as lost: a reason is requested

**My Pipeline / All Deals**

- By default you see only your own deals
- Click **"All Deals"** to see the full pipeline *(MASTER and C-Level only)*

---

### General tips

- **Profile:** complete your name and photo in the **Profile** section so teammates can identify you
- **Notification bell:** the red number shows unread messages; click to mark as read
- **Real-time updates:** the platform refreshes automatically when you switch tabs or every 20 seconds
